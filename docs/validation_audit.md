# Feasibility Validation Audit

## Conclusion

The current application data do not provide sufficiently aligned cohorts to validate the pilot feasibility prototypes. Housing applications remain an independent historical context layer and must not be presented as the next step of the financial screen.

## Why the initial overlap was misleading

The initial comparison showed applications on 2 of 140 baseline-positive parcels (1.43%) and 163 of 11,577 favorable-positive parcels (1.41%). Because the baseline group is nested within the favorable group and incidence is essentially identical, this comparison provides no evidence that the binary feasibility threshold distinguishes application locations.

The comparison was also misaligned: the current financial model tests a for-sale duplex, rental duplex, and four-unit rental rowhouse, while the application subset contains single-family homes, ADUs, multiple middle-housing products, and larger multifamily projects without dependable tenure classification. Most applications predate the February 1, 2025 Home in Tacoma effective date. Development decisions also depend on ownership, timing, financing, assembly, and constraints outside this model, while exact parcel matching can miss parcel changes and multi-parcel projects.

## Earlier four-unit cohort diagnostic

An earlier diagnostic used applications on or after February 1, 2025 and a transparent text/unit screen for four-unit townhouse, rowhouse, or fourplex projects. It produced:

- 597 housing-development application records after the policy effective date;
- 14 four-unit townhouse-like permit records;
- 6 unique parcel identifiers among those records;
- 5 unique parcels after matching to the current parcel base; and
- 4 unique parcels in the current UR candidate scope that pass the basic physical screen.

This sample is too small for an incidence comparison or predictive-validity claim and is not a validation cohort for either duplex model or specifically for rental tenure. Nine records also reference the same parcel/project, illustrating why record counts cannot be treated as independent development events.

## Additional temporal problem

The acquisition benchmark uses current assessed land plus improvement value. For parcels with recent construction applications, current improvement value may reflect work occurring after the original acquisition or application decision. Comparing that value with a predevelopment residual land value can reverse the intended time order and make successful projects appear infeasible.

## Display decision

- Remove housing applications from the development screening funnel.
- Retain applications only as an independently labeled 2021–2026 context map.
- Do not describe application overlap as validation.
- Revisit validation only with predevelopment property values, project/product classification, policy-aligned dates, deduplicated projects, and parcel lineage/assembly matching.
